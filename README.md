# Time SMP (Fabric Mod)

ม็อดเซิร์ฟเวอร์ Fabric (Server-only) สำหรับ Minecraft 26.2 และ 26.3 (Java 25, Fabric API) พัฒนาเพื่อรองรับระบบเศรษฐกิจ ตลาดประมูล การค้าขาย และระบบจัดการโฉนดที่ดินแบบสมบูรณ์ 100% ภายในตัวเกมผ่านระบบเมนู Chest GUI และ Custom UI

---

## จุดเด่นของระบบ (Key Features)

- **ระบบเมนูในตัวเกม 100% (In-Game Custom UI):** ไม่จำเป็นต้องใช้เบราว์เซอร์หรือติดตั้งเว็บเซิร์ฟเวอร์ภายนอก ผู้เล่นสามารถจัดการทุกระบบได้ในเกมโดยตรง
- **ระบบประมูลแข่งขันราคา (/ah):** แข่งขันเสนอราคาอย่างโปร่งใส ไม่มีระบบซื้อทันที พร้อมปุ่มเพิ่มราคาประมูลอย่างรวดเร็ว (+500, +1,000, +5,000) และปุ่มสำหรับเจ้าของรายการกดปิดประมูลขายให้ผู้เสนอราคาสูงสุดได้ทันที
- **ระบบร้านค้าและราคากลาง (/shop, /sell, /price):** ระบบราคากลางอิงอุปสงค์-อุปทานแบบ Real-time พร้อมเมนูลากวางไอเท็มเพื่อประเมินและขายทันที
- **ระบบโฉนดที่ดินและแผนที่เรดาร์ (/claim, /map):** แบ่งที่ดินเป็นตารางแบบ Block Grid ตรวจสอบสถานะการครอบครองผ่านแผนที่เรดาร์ในเกม พร้อมปุ่มเข็มทิศเลื่อนหาตำแหน่งผู้เล่น และระบบวาร์ปสุ่มพิกัดที่ดินพร้อมคำนวณความสูง Y ที่ปลอดภัย
- **การจัดการสมาชิกที่ดิน (/claim add, /claim remove):** อนุญาตให้เพื่อนร่วมสร้างและเปิดกล่อง หรือเพิกถอนสิทธิ์ได้ทันที
- **ระบบกล่องจดหมายรับของ (/mail):** จัดเก็บไอเท็มและเงินจากการชนะประมูลหรือการคืนสินค้าอย่างปลอดภัย
- **ระบบรักษาความปลอดภัยบัญชี (/pass):** บันทึกรหัสผ่านแบบ PBKDF2 ป้องกันการสวมรอยในโหมด Offline

## การบิลด์ม็อด (Build)

ม็อดตั้งค่าบิลด์ผ่าน **GitHub Actions** (`.github/workflows/build.yml`) ซึ่งจะทำงานและส่งออก Artifacts อัตโนมัติทุกครั้งที่ผลักข้อมูลขึ้นสู่ GitHub

```bash
# บิลด์สำหรับ Minecraft 26.3 (ค่าเริ่มต้น)
./gradlew build

# บิลด์สำหรับ Minecraft 26.2
./gradlew build -Pminecraft_version=26.2 -Pfabric_api_version=0.161.0+26.2
```

ไฟล์ Jar ที่ได้จะอยู่ที่ `build/libs/timesmp-mc<version>-1.0.0.jar`

## การติดตั้งบนเซิร์ฟเวอร์

1. นำไฟล์ `timesmp.jar` ไปวางในโฟลเดอร์ `mods/` ของเซิร์ฟเวอร์ Fabric
2. เริ่มต้นรันเซิร์ฟเวอร์เพื่อสร้างการตั้งค่าเริ่มต้นที่ `config/timesmp/timesmp.properties`
3. Resource Pack (ฟอนต์ภาษาไทย/ไอคอนปุ่ม) ส่งผ่าน HTTPS จาก GitHub Release `latest` — ตั้งค่าใน `server.properties` ด้วย `resource-pack=` (หรือใช้ `setup.sh` ซึ่งจัดการให้อัตโนมัติ) ม็อดไม่เปิดพอร์ตเว็บใด ๆ

### `setup.sh` จัดการให้อัตโนมัติ

- โหลด Fabric server, Fabric API และ Time SMP (build ล่าสุด)
- โหลดม็อดสร้างโลกสำหรับโลกหลัก (lithostitched + tectonic) สำหรับ 26.3
- โหลดม็อดเสริม (sit + otterlib) สำหรับ 26.3
- โหลดโลก `lobby` จาก `world-lobby-2026-11-17.zip` ไปวางที่ `worlds/lobby` และล้างข้อมูลผู้เล่นทั้งหมด (player data / advancements / stats)
- สร้าง `run.sh` ให้เลือกแรมได้

### PvP ในเขตที่ดิน

- เจ้าของเขตเปิด/ปิด PvP ได้จากเมนูจัดการเขต (ไอคอนดาบ/โล่)
- กฎใช้กับทุกเขต: เมื่อปิด PvP ผู้เล่นในเขตนั้นตีกันไม่ได้ ส่วนพื้นที่ว่าง (unclaimed) ยังใช้ค่า `pvp` ของเซิร์ฟเวอร์
- ค่าเริ่มต้นของเขตใหม่คือ `pvp=true` (ตีกันได้) ตามค่า `pvp=true` ของเซิร์ฟเวอร์

## โครงสร้างข้อมูลที่บันทึก (JSON Data)

| ไฟล์ | รายละเอียดการจัดเก็บ |
| :--- | :--- |
| `config/timesmp/accounts.json` | ฐานข้อมูลบัญชีผู้เล่นและรหัสผ่าน PBKDF2 (ไม่มีการบันทึกรหัสแบบข้อความเปล่า) |
| `config/timesmp/regions.json` | ฐานข้อมูลการถือครองที่ดิน เจ้าของ และรายชื่อสมาชิกในแปลง |
| `config/timesmp/economy.json` | ฐานข้อมูลบัญชีการเงินและประวัติการทำธุรกรรม |
| `config/timesmp/auctions.json` | รายการประมูลสินค้าและที่ดินที่กำลังดำเนินการ |
| `config/timesmp/mailbox.json` | รายการพัสดุและไอเท็มรอรับของผู้เล่นแต่ละคน |
