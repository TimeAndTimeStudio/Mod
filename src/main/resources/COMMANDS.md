## 1. ระบบประมูล & ตลาดผู้เล่น (/ah, /buy)

ระบบซื้อขายแลกเปลี่ยนระหว่างผู้เล่น รองรับทั้งการประมูลแข่งราคา (Auction) และการซื้อทันที (Buyout)

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/ah` | `/ah` | เปิดหน้าต่างเมนูตลาดประมูลรวม (Chest GUI) |
| `/ah sell` | `/ah sell <ราคาเริ่มต้น> [ราคาซื้อทันที] [ชั่วโมง]` | นำไอเท็มที่กำลังถืออยู่ในมือหลักขึ้นประมูล |
| `/ah bid` | `/ah bid <รหัสรายการ> <จำนวนเงิน>` | เสนอราคาประมูลแข่งในรายการที่ต้องการ |
| `/ah buyout` | `/ah buyout <รหัสรายการ>` | ซื้อสินค้าทันทีตามราคา Buyout (ไม่ต้องรอหมดเวลา) |
| `/ah cancel` | `/ah cancel <รหัสรายการ>` | ยกเลิกรายการที่ตนเองลงขาย (หากยังไม่มีผู้เสนอราคา) |
| `/ah list` | `/ah list [หน้า]` | ดูรายการประมูลที่กำลังดำเนินอยู่ผ่านทางแชท |
| `/ah my` | `/ah my` | ดูรายการที่ตนเองเป็นคนลงประมูลไว้ |
| `/buy` | `/buy` | เปิดเมนูเรียกดูเฉพาะสินค้าไอเท็มที่ผู้เล่นลงขาย |

### ตัวอย่างการใช้งาน:
- **ลงขายดาบเพชรในมือ:** 
  `/ah sell 100 300 24`
  *(ราคาเริ่ม 100 เหรียญ, ซื้อทันที 300 เหรียญ, ระยะเวลา 24 ชั่วโมง)*
- **เสนอราคาประมูลรายการ #5:**
  `/ah bid 5 150`
- **ซื้อทันทีรายการ #5:**
  `/ah buyout 5`

> [!NOTE]
> เมื่อชนะการประมูลหรือขายสินค้าสำเร็จ เงินและไอเท็มจะถูกส่งเข้ากล่องจดหมายโดยอัตโนมัติ ให้พิมพ์ `/mail` เพื่อเปิดรับของ

## 2. ระบบขายของ & ราคากลาง (/sell, /price)

ระบบขายไอเท็มที่หามาได้ให้กับเซิร์ฟเวอร์ตามราคากลางแบบ Real-time ตามกลไกอุปสงค์-อุปทาน

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/sell` | `/sell` | เปิดเมนู Chest GUI สำหรับวางไอเท็มขายให้เซิร์ฟเวอร์ทันที |
| `/sell hand` | `/sell hand [จำนวน]` | ขายไอเท็มที่กำลังถืออยู่ในมือให้เซิร์ฟเวอร์ |
| `/sell all` | `/sell all` | ขายไอเท็มทุกชิ้นในตัวที่ชนิดเดียวกับไอเท็มในมือ |
| `/price` | `/price` | เปิดหน้าต่าง GUI ตรวจสอบราคากลางของสินค้าทุกชนิด |
| `/price hand` | `/price hand` | เช็คราคารับซื้อของไอเท็มที่กำลังถืออยู่ในมือ |
| `/price <id>` | `/price <ชื่อไอเท็ม>` | เช็คราคารับซื้อของไอเท็มที่ระบุ เช่น `/price diamond` |

### วิธีใช้งาน GUI `/sell`:
1. พิมพ์คำสั่ง `/sell` ในเกม
2. ใส่ไอเท็มที่ต้องการขายลงในช่องว่างด้านบน (ช่อง 1–45)
3. ปิดหน้าต่าง GUI หรือกดปุ่มกากบาท `[ปิดหน้าต่าง & ขายทันที]`
4. ระบบจะคำนวณราคาตามราคากลางและโอนเงินเข้ากระเป๋าของคุณทันที

## 3. ระบบที่ดิน & แผนที่เรดาร์ (/claim, /claimmap, /map)

ระบบปกป้องพื้นที่ ปลูกสร้าง และการซื้อขายกรรมสิทธิ์ที่ดินขนาดใหญ่ (Cell ขนาด 500x500 บล็อก)

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/claimmap` หรือ `/map` | `/claimmap` | เปิดหน้าต่างเรดาร์แผนที่ในเกม (Interactive Radar GUI) |
| `/claim` | `/claim` | จับจองหรือซื้อกรรมสิทธิ์เขตที่ดินในตำแหน่งที่กำลังยืนอยู่ |
| `/claim info` | `/claim info` | ดูข้อมูลเขตที่กำลังยืนอยู่ (พิกัด, เจ้าของ, สมาชิก) |
| `/claim unclaim` | `/claim unclaim` | สละสิทธิ์/ปล่อยที่ดินเขตที่กำลังยืนอยู่กลับเป็นที่ว่าง |
| `/claim transfer` | `/claim transfer <ชื่อผู้เล่น>` | โอนกรรมสิทธิ์เขตที่ยืนอยู่ให้ผู้เล่นคนอื่น |
| `/claim add` | `/claim add <ชื่อผู้เล่น>` | เพิ่มเพื่อนเป็นสมาชิกในเขต (ให้สิทธิ์เปิดกล่อง/สร้าง) |
| `/claim remove` | `/claim remove <ชื่อผู้เล่น>` | ลบสมาชิกออกจากเขต |
| `/claim auction` | `/claim auction <ราคาเริ่ม> [ซื้อทันที] [ชม.]` | นำเขตที่ดินที่ยืนอยู่ขึ้นประมูลในตลาด `/ah` |

### การเปิดประมูลที่ดินผ่านหน้าจอ GUI `/claimmap`:
1. พิมพ์คำสั่ง `/map` หรือ `/claimmap`
2. คลิกเลือกที่ช่องเขตของตนเอง (ช่องสีเขียว)
3. หน้าต่างจะเปลี่ยนเป็นรายละเอียดเขต
4. กดที่ปุ่ม **[ประมูล] เปิดประมูลเขตนี้**
5. ที่ดินจะถูกนำขึ้นตลาด `/ah` ให้ผู้เล่นอื่นแข่งขันเสนอราคาได้ทันที

> [!TIP]
> ผู้เล่นทุกคนได้รับสิทธิ์จับจองที่ดิน **ฟรี 4 เขตแรก**! หลังจากครบ 4 เขตแล้ว สามารถซื้อเขตถัดไปได้ไม่จำกัดตามราคาประเมินที่ดิน

## 4. ระบบการเงิน & กล่องจดหมาย (/bal, /pay, /mail)

การบริหารกระเป๋าเงิน การโอนเงินระหว่างผู้เล่น และระบบกล่องจดหมายรับของรางวัล

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/bal` หรือ `/money` | `/bal` | ตรวจสอบยอดเงินคงเหลือในบัญชีของคุณ |
| `/pay` | `/pay <ชื่อผู้เล่น> <จำนวน>` | โอนเงินจากกระเป๋าของคุณให้ผู้เล่นอื่น |
| `/mail` หรือ `/mail gui` | `/mail` | เปิดหน้าต่างกล่องจดหมายเพื่อรับไอเท็มและเงินรางวัล |
| `/mail claim` | `/mail claim` | กดรับไอเท็มและเงินทั้งหมดในกล่องจดหมายเข้าตัวทันที |
| `/mail list` | `/mail list` | ดูรายการจดหมายและของที่ค้างอยู่ผ่านทางแชท |

## 5. ระบบบัญชี & รหัสผ่าน (/pass)

ใช้สำหรับตั้งรหัสผ่านความปลอดภัยในการเข้าใช้งานพอร์ทัลเว็บไซต์ หรือป้องกันบัญชี

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/pass set <รหัสผ่าน>` | ตั้งรหัสผ่านใหม่สำหรับบัญชีผู้เล่นของคุณ |
| `/pass change <รหัสเก่า> <รหัสใหม่>` | เปลี่ยนรหัสผ่านเดิมเป็นรหัสใหม่ |

---

## 6. ระบบเทเลพอร์ต & วาร์ป (/tpa, /spawn, /world)

ระบบขอเดินทางไปหาเพื่อน และการเดินทางระหว่างโลกต่าง ๆ ในเซิร์ฟเวอร์

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/tpa <ชื่อผู้เล่น>` | ส่งคำขอเทเลพอร์ตไปหาผู้เล่นเป้าหมาย |
| `/tpaccept` | กดตอบรับคำขอเทเลพอร์ตที่มีคนส่งมาหาคุณ |
| `/tpdeny` | ปฏิเสธคำขอเทเลพอร์ต |
| `/tpacancel` | ขอยกเลิกคำขอเทเลพอร์ตที่คุณเพิ่งส่งออกไป |
| `/spawn` หรือ `/main` | วาร์ปกลับไปยังจุดเกิดหลักของเซิร์ฟเวอร์ |
| `/world` | ดูรายชื่อโลกทั้งหมดในเซิร์ฟเวอร์ |
