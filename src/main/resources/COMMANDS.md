# [Time SMP] คู่มือคำสั่งและระบบทั้งหมดในเกม (Commands Manual)

คู่มือนี้รวบรวมคำสั่ง ระบบ GUI และวิธีใช้งานทั้งหมดของเซิร์ฟเวอร์ Time SMP จัดการทุกระบบผ่านภายในตัวเกมอย่างสมบูรณ์แบบ 100% พร้อมปุ่มไอคอนจำลองแบบ Pixel Art ไม่มีพื้นหลัง โปร่งใสสวยงาม สร้างจาก SVG (Custom UI Item Buttons) และข้อความภาษาไทยที่อ่านง่าย ชัดเจน

> ทุกหน้าต่างเมนู GUI ในเซิร์ฟเวอร์สามารถกดปุ่ม **Esc** บนคีย์บอร์ดเพื่อปิดหน้าต่างได้ทันที (ไม่มีปุ่มปิดหน้าต่างบนหน้าจอ)  
> ทุกระบบการวาร์ปและเทเลพอร์ตจะมีเวลานับถอยหลังเตรียมตัว **5 วินาที** (ห้ามขยับตัว หากเดินหรือกระโดดการวาร์ปจะถูกยกเลิกทันที)

## 1. เมนูคู่มือช่วยเหลือและคำสั่ง (/help, /smphelp, /menu)

ศูนย์ช่วยเหลือแบบ Interactive GUI รวมทุกคำสั่งสำคัญไว้ในหน้าจอเดียว ผู้เล่นสามารถคลิกที่ไอคอนแต่ละระบบเพื่อเปิดใช้งานหรือดูคำสั่งลัดได้ทันที

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/help` | `/help` | เปิดหน้าต่างเมนูคู่มือช่วยเหลือและคำสั่งทั้งหมด |
| `/smphelp` | `/smphelp` | คำสั่งสำรองสำหรับเปิดเมนูคู่มือช่วยเหลือ |
| `/menu` | `/menu` | ทางลัดเปิดเมนูหลักของเซิร์ฟเวอร์ |

## 2. ระบบประมูลระหว่างผู้เล่น (/ah)

ระบบประมูลแข่งขันราคาระหว่างผู้เล่น (Competitive Auction) โดยไม่มีร้านค้าจากเซิร์ฟเวอร์เพื่อให้ผู้เล่นขับเคลื่อนเศรษฐกิจกันเองอย่างแท้จริง

### หน้าต่าง Interactive Bid Increment Screen
เมื่อผู้เล่นคลิกที่รายการสินค้าใน `/ah` จะเปิดหน้าต่างเสนอราคา:
- **ปุ่มเหรียญเสนอราคา (Coin):** เสนอราคาขั้นต่ำ (Min Bid) หรือเลือกเพิ่มราคาแบบด่วน (+500, +1,000, +5,000, +10,000 เหรียญ)
- **ปุ่มแชทระบุราคาเอง (Chat):** แนะนำรูปแบบคำสั่งพิมพ์ระบุจำนวนเงินประมูลเองผ่านช่องแชท
- **ปุ่มยกเลิกประมูล (Cancel):** [ยกเลิกการประมูล] สำหรับเจ้าของรายการ เพื่อยกเลิกและรับไอเท็มคืนเข้ากล่อง `/mail` (หากมีผู้เสนอราคา ระบบจะคืนเงินเต็มจำนวนให้ผู้เสนอราคาทันที)

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/ah` | `/ah` | เปิดหน้าต่างเมนูตลาดประมูลรวม |
| `/ah sell` | `/ah sell <ราคาเริ่มต้น> [ชั่วโมง]` | นำไอเท็มในมือขึ้นประมูล (ค่าเริ่มต้น 24 ชม.) |
| `/ah cell` | `/ah cell <cellId> <ราคาเริ่มต้น> [ชั่วโมง]` | นำโฉนดที่ดินขึ้นประมูล |
| `/ah bid` | `/ah bid <รหัสรายการ> <จำนวนเงิน>` | เสนอราคาประมูลแข่งในรายการที่ต้องการ |
| `/ah cancel` | `/ah cancel <รหัสรายการ>` | ยกเลิกรายการประมูลของตนเอง (คืนเงินให้ผู้เสนอราคา และส่งของคืนเข้า /mail) |
| `/ah list` | `/ah list` | ดูรายการประมูลที่เปิดอยู่ผ่านทางแชท |

## 3. ระบบขายของ & ราคากลาง (/sell, /price)

ระบบขายไอเท็มให้กับเซิร์ฟเวอร์เพื่อรับเงินเข้ากระเป๋าตามราคากลางแบบ Real-time

### วิธีใช้งานเมนู `/sell`:
1. พิมพ์ `/sell` เพื่อเปิดหน้าต่างวางไอเท็ม
2. วางไอเท็มที่ต้องการขายในช่อง 1 ถึง 45
3. กดปุ่ม **Esc** บนคีย์บอร์ดเพื่อปิดหน้าต่าง ระบบจะทำการขายไอเท็มทั้งหมดและโอนเงินเข้าบัญชีทันที

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/sell` | `/sell` | เปิดหน้าต่างเมนูวางของขายทันที |
| `/sell hand` | `/sell hand` | ขายไอเท็มทั้งหมดในมือหลักให้กับเซิร์ฟเวอร์ทันที |
| `/sell all` | `/sell all` | ขายไอเท็มชนิดเดียวกับในมือทั้งหมดที่มีอยู่ในตัวกระเป๋า |
| `/price` | `/price` | เปิดหน้าต่าง GUI ตรวจสอบราคากลางของสินค้าทั้งหมด |
| `/price hand` | `/price hand` | ดูราคากลางและแนวโน้มราคาของไอเท็มที่ถืออยู่ในมือ |

## 4. ระบบที่ดิน & แผนที่เรดาร์ (/claim, /map)

ระบบจัดการโฉนดที่ดินแบบ Grid พร้อมแผนที่เรดาร์ในเกมที่เชื่อมต่อกับตำแหน่งของผู้เล่นอย่างแม่นยำ

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/claim` | `/claim` | ซื้อ/รับสิทธิ์เขตที่ดินแปลงที่กำลังยืนอยู่ทันที |
| `/claim add <ชื่อ>` | `/claim add <ชื่อผู้เล่น>` | เพิ่มเพื่อนเป็นสมาชิก อนุญาตให้สร้างและเปิดกล่องในแปลงได้ |
| `/claim remove <ชื่อ>` | `/claim remove <ชื่อผู้เล่น>` | ลบสิทธิ์เพื่อนออกจากแปลงที่ดิน |
| `/claim tf <ชื่อ>` | `/claim tf <ชื่อผู้เล่น>` | โอนกรรมสิทธิ์ที่ดินแปลงปัจจุบันให้ผู้เล่นอื่น |
| `/claim at <ราคา> [ชม.]` | `/claim at <ราคาเริ่ม> [ชั่วโมง]` | นำโฉนดที่ดินขึ้นประมูลในตลาด `/ah` |
| `/claim tp <cellId>` | `/claim tp 5,5` | วาร์ปไปยังเขตที่ดิน (รอ 5 วินาที สุ่มพิกัดปลอดภัยไม่ติดบล็อก) |
| `/map` | `/map` | เปิดหน้าต่างแผนที่เรดาร์ Mini Grid สำรวจที่ดินรอบตัว |

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/sethome [ชื่อ]` | `/sethome [ชื่อบ้าน]` | บันทึกจุดเซฟบ้าน ณ ตำแหน่งที่ยืน (ค่าเริ่มต้น: home) |

| `/home` | `/home` | เปิดหน้าต่าง GUI แสดงรายการบ้านทั้งหมด คลิกซ้ายเพื่อวาร์ป (รอ 5 วิ) หรือคลิกขวาเพื่อลบ |
| `/home <ชื่อ>` | `/home <ชื่อบ้าน>` | วาร์ปไปยังบ้านที่ระบุโดยตรง (รอ 5 วินาที) |

## 7. ระบบยืนยันตัวตน & แอดมินรีเซ็ตรหัส (/auth reset)

ระบบความปลอดภัยของเซิร์ฟเวอร์ทำงานอัตโนมัติผ่านหน้าต่างกล่องข้อความ Native Dialog ขณะเชื่อมต่อเข้าเซิร์ฟเวอร์ (ไม่ต้องพิมพ์คำสั่งในแชท)
- ผู้เล่นใหม่จะพบหน้าต่าง **ตั้งรหัสผ่านครั้งแรก** อัตโนมัติเมื่อเข้าเซิร์ฟเวอร์
- ผู้เล่นเดิมจะพบหน้าต่าง **เข้าสู่ระบบ** อัตโนมัติเมื่อเข้าเซิร์ฟเวอร์

### คำสั่งแอดมิน:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/auth reset <ชื่อ>` | `/auth reset <ชื่อผู้เล่น>` | แอดมินสั่งรีเซ็ตรหัสผ่านของผู้เล่นเป้าหมาย โดยเตะผู้เล่นออกจากเซิร์ฟเวอร์เพื่อให้ตั้งรหัสผ่านใหม่เมื่อเข้าเกมครั้งถัดไป |
| `/pass reset <ชื่อ>` | `/pass reset <ชื่อผู้เล่น>` | คำสั่งทางเลือกสำหรับแอดมินในการรีเซ็ตรหัสผ่าน |

## 8. ระบบเทเลพอร์ต & ข้ามโลก (/tpa, /spawn, /main, /<ชื่อโลก>)

ทุกระบบการเทเลพอร์ตมีระยะเวลาเตรียมตัว **5 วินาที** พร้อมแถบแจ้งเตือน Action Bar หากผู้เล่นขยับตัวจะยกเลิกการวาร์ปทันที

### หน้าต่างเมนูเทเลพอร์ต (/tpa GUI):
เมื่อผู้เล่นพิมพ์คำสั่ง `/tpa` (หรือคลิกเมนูวาร์ปใน `/help`) จะเปิดหน้าต่าง Chest GUI จัดการการวาร์ปครบวงจร:
- **แถบคำขอวาร์ปที่รอการตอบรับ (แยกตามรายชื่อผู้เล่น):**
  - **คลิกซ้าย:** กดยอมรับคำขอวาร์ปจากผู้เล่นคนนั้น (ผู้เล่นต้นทางจะเริ่มนับถอยหลังวาร์ป 5 วินาที)
  - **คลิกขวา:** ปฏิเสธ / ยกเลิกคำขอวาร์ปจากผู้เล่นคนนั้น
- **แถบรายชื่อผู้เล่นออนไลน์:**
  - แสดงผู้เล่นที่ออนไลน์ในเซิร์ฟเวอร์ทั้งหมดพร้อมระบุโลกปัจจุบัน
  - **คลิกซ้าย:** ส่งคำขอวาร์ปไปหาผู้เล่นนั้นทันที (เทียบเท่า `/tpa <ชื่อผู้เล่น>`)
- **ปุ่มสถานะคำขอที่ส่งออกไป:**
  - แสดงชื่อผู้เล่นปลายทางที่กำลังรอการตอบรับ
  - คลิกซ้ายหรือคลิกขวาเพื่อยกเลิกคำขอที่ส่งไปได้ทันที

### คำสั่งหลัก:
| คำสั่ง | รูปแบบการใช้งาน | คำอธิบาย |
| :--- | :--- | :--- |
| `/tpa` | `/tpa` | เปิดหน้าต่างเมนูเทเลพอร์ต (เลือกผู้เล่นเพื่อวาร์ปหา หรือกดยอมรับ/ปฏิเสธคำขอ) |
| `/tpa <player>` | `/tpa <ชื่อผู้เล่น>` | ส่งคำขอเทเลพอร์ตไปหาผู้เล่นเป้าหมายโดยตรง |
| `/tpa accept` | `/tpa accept [ชื่อผู้เล่น]` | ยอมรับคำขอวาร์ปผ่านแชท (ผู้ส่งจะเริ่มนับถอยหลัง 5 วินาที) |
| `/tpa deny` | `/tpa deny [ชื่อผู้เล่น]` | ปฏิเสธคำขอวาร์ปผ่านแชท |
| `/tpa cancel` | `/tpa cancel` | ยกเลิกคำขอวาร์ปที่ส่งไป |
| `/spawn` | `/spawn` | วาร์ปกลับจุดเกิดหลักของเซิร์ฟเวอร์ (รอ 5 วินาที) |
| `/main` | `/main` | วาร์ปกลับโลกหลัก ณ ตำแหน่งเดิม (รอ 5 วินาที) |
| `/<ชื่อโลก>` | `/<ชื่อโลก>` | ข้ามไปยังโลกมิติอื่นโดยตรง เช่น `/mining` (รอ 5 วินาที) |

## 9. ไอคอนปุ่มกด Pixel Art โปร่งใสจาก SVG (Custom UI Item Buttons)

เมนูในเกมทั้งหมดติดตั้ง Resource Pack ไอคอนปุ่มกดแบบ Pixel Art 16x16 โปร่งใส ไม่มีพื้นหลังกรอบสี่เหลี่ยม สร้างและควบคุมลายเส้นจาก SVG:
- **ปุ่มช่วยเหลือ (Help):** รูปหนังสือเรืองแสง/เครื่องหมายคำถาม
- **ปุ่มนำทาง (Nav Arrows & Center):** ลูกศรพิกเซลชี้ทิศ เหนือ (แดง), ใต้ (น้ำเงิน), ออก, ตก และปุ่มเป้าหมายมรกตตรงกลาง
- **ปุ่มจองที่ดิน (Claim Flag):** ธงสีเขียวบนเสาไม้
- **ปุ่มวาร์ป (Warp):** ประตูมิติเอนเดอร์สีม่วง สำหรับปุ่มวาร์ปที่ดินและระบบบ้าน
- **ปุ่มยกเลิกประมูล (Cancel):** กากบาทสีแดง สำหรับยกเลิกการประมูล
- **ปุ่มเหรียญเสนอราคา (Coin):** เหรียญทองคำเปล่งประกาย (+500, +1,000, +5,000, +10,000)
- **ปุ่มระบุราคาเอง (Chat Bubble):** กล่องข้อความแชทสีขาว-เขียว
- **ปุ่มย้อนกลับ / ถัดไป (Back / Next):** ลูกศรพิกเซลสีขาว-ฟ้า
- **ปุ่มโลโก้ TimeSMP (Brand Logo):** นาฬิกาทองคำแสดงเวลา
- **การปิดเมนู:** สามารถกดปุ่ม Esc บนคีย์บอร์ดเพื่อปิดหน้าต่างเมนูทุกชนิดได้ทันที
