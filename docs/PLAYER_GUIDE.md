# คู่มือผู้เล่น Claim Map

## เข้าเว็บ

เปิดเบราว์เซอร์ไปที่ `http://<IP ของเซิร์ฟเวอร์>:8085/` แล้วล็อกอินด้วย **ชื่อผู้เล่นในเกม** และรหัสผ่านเดียวกับที่ตั้งในเกม

> ⚠️ ระบบใช้ HTTP ธรรมดา (ไม่เข้ารหัส) ใช้ในวง LAN/VPN ที่ไว้ใจได้เท่านั้น และ **อย่าใช้รหัสซ้ำกับบริการอื่น**

## ตั้งรหัส / ใส่รหัสตอนเข้าเกม

ตอนเชื่อมต่อเซิร์ฟเวอร์ จะมี **หน้าต่างของเกม** ขึ้นก่อนเข้าโลก:

- **ครั้งแรก** — หน้าต่าง “ตั้งรหัสผ่านครั้งแรก” ให้กรอกรหัสใหม่และยืนยันรหัส
- **ครั้งต่อไป** — หน้าต่าง “เข้าสู่ระบบ” ให้กรอกรหัสเดิม
- กดปุ่ม “เข้าสู่เกม” เพื่อดำเนินการ หรือ “ออกจากเกม” เพื่อยกเลิก
- ยังไม่ผ่านรหัสจะเข้าโลกไม่ได้เลย (ค้างอยู่ช่วงเชื่อมต่อ)
- ถ้าเปลี่ยนรหัสภายหลัง ใช้ `/pass <รหัสเดิม> <รหัสใหม่>` ในเกม

- รหัสยาว 6–64 ตัวอักษร และต้องไม่เหมือนชื่อผู้เล่น
- ใส่รหัสผิด 3 ครั้ง หรือไม่กรอกภายใน 60 วินาที จะถูกตัดการเชื่อมต่อ
- รหัสเดียวใช้ได้ทั้งในเกมและเว็บ

## คำสั่งหลักในเกม

| คำสั่ง | ความหมาย |
|---|---|
| `/bal` | ดูกระเป๋าเงิน |
| `/pay <ผู้เล่น> <จำนวน>` | โอนเงินให้ผู้เล่นอื่น |
| `/sell hand` | ขายของในมือให้ร้าน |
| `/sell all` แล้ว `/sell all confirm` (ภายใน 30 วิ) | ขายของที่ขายได้ทั้งหมด |
| `/buy <item> <จำนวน>` | ซื้อจากร้าน (ของเข้ากล่องของ) |
| `/mail` | ดูก่อนของในกล่อง |
| `/mail claim` | รับของจากกล่องเข้าเกม |
| `/ah` | สรุปประมูล + ที่อยู่เว็บ |
| `/ah sell <ราคาเริ่ม> [ซื้อทันที] [ชั่วโมง]` | ลงขายของในมือ |
| `/ah bid <id> <จำนวน>` | เสนอราคา |
| `/ah cancel <id>` | ยกเลิกประมูลที่ยังไม่มีคนเสนอ |
| `/claim` | จองช่องที่ยืนอยู่ |
| `/claimmap here` | ดูข้อมูลช่องปัจจุบัน |

## แอปในเว็บ

- **แผนที่** — ลากเลื่อน แตะเลือกช่อง สีส้มคือของคุณ สีแดงคือของคนอื่น
- **ลงขาย** — มี 2 แท็บ
  - *ตลาดผู้เล่น* — เลือกของจาก **กระเป๋า, Ender Chest หรือกล่องทุกใบในช่องที่คุณเป็นเจ้าของ/สมาชิก** ใส่จำนวน ราคาเริ่ม ราคาซื้อทันที (ไม่บังคับ) และจำนวนชั่วโมง ของจะถูกย้ายออกจากช่องนั้นทันที ถ้ายกเลิกหรือหมดเวลาโดยไม่มีคนซื้อ ของจะกลับเข้ากล่องของ
  - *ขายให้ร้าน* — ขายของในกระเป๋าหลัก/แถบด่วนตามราคาร้าน (ขายของที่มี enchant/ชื่อเอง/ความเสียหายไม่ได้)
- **ซื้อ** — มีทั้งของจากร้านและของที่ผู้เล่นลงขาย (ซื้อทันทีได้จากหน้านี้) ปุ่ม **＋ ลงขาย** พาไปหน้าลงขาย · ของที่ซื้อจะเข้ากล่องของก่อน แล้วค่อย `/mail claim` ในเกม
- **ประมูล** — เสนอราคา/ซื้อทันที/ยกเลิก (ลงขายได้ทั้งจากหน้าเว็บ “ลงขาย” และ `/ah sell` ในเกม)
- **เทรด** — แลกของกับผู้เล่นอื่นแบบของต่อของ
  - *ตั้งข้อเสนอ* — เลือกของที่จะให้ (จากกระเป๋า/Ender Chest/กล่องในพื้นที่) ใส่ item id และจำนวนของที่ต้องการ เช่น `minecraft:iron_ingot` × 32 ของที่ให้ถูกเก็บไว้ทันที
  - *รับเทรด* — เลือกช่องที่มีของที่เขาต้องการ แล้วกด “รับเทรด” ทั้งสองฝ่ายได้ของเข้ากล่องของ
  - ข้อเสนออยู่ได้ 7 วัน เปิดพร้อมกันได้สูงสุด 10 รายการต่อคน ยกเลิกได้ตลอด (รวมถึงหลังหมดอายุ) เพื่อรับของคืนเข้ากล่องของ
  - ระบบเช็กแค่ **ชนิดไอเท็มและจำนวน** ของที่ได้รับอาจมีความเสียหาย/enchant ต่างกันได้ — ตรวจให้ดีก่อนตั้งข้อเสนอ
- การดึงของจากกล่อง/เทรด **ต้องออนไลน์ในเกม** และกล่องต้องอยู่ใน chunk ที่โหลดอยู่ (เช่น อยู่ใกล้ผู้เล่น)
- **กระเป๋าเงิน** — ดูประวัติและโอนเงิน
- **กล่องของ** — รับของ (ต้องออนไลน์ในเกม)
- **ราคา** — ตารางราคาซื้อ/ขายล่าสุด
- **แอดมิน** — เห็นเฉพาะบัญชีที่อยู่ในรายชื่อ `admins`

ทุกปุ่มที่ใช้เงินจะมียืนยันและแสดงยอดคงเหลือหลังทำรายการก่อนเสมอ
