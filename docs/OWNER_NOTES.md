# แนวทางการดูแลระบบสำหรับเจ้าของเซิร์ฟเวอร์ (Owner Notes)

## 1. การตั้งค่าระบบหลัก (`config/timesmp/timesmp.properties`)

| ตัวแปร | ค่ามาตรฐาน | คำอธิบาย |
| :--- | :--- | :--- |
| `cellSize` | `16` | ขนาดของแต่ละเขตที่ดิน (บล็อก) |
| `freeCellsPerPlayer` | `4` | จำนวนช่องที่ดินที่ผู้เล่นสามารถครอบครองได้ฟรี |
| `auctionMaxHours` | `72` | ระยะเวลาเปิดประมูลสูงสุด (ชั่วโมง) |
| `startingBalance` | `1000` | เงินเริ่มต้นของผู้เล่นใหม่เมื่อลงทะเบียน |

### เวลาจริงและสภาพอากาศของ Lobby

| ตัวแปร | ค่ามาตรฐาน | คำอธิบาย |
| :--- | :--- | :--- |
| `lobbyRealTime` | `true` | ใช้เวลาจริงจากเว็บภายนอกกับนาฬิกา Lobby (ไม่พึ่งนาฬิกาเครื่อง) |
| `lobbyTimeZone` | `UTC+7` | เขตเวลาที่ใช้แปลงเวลาจริงเป็นเวลาในเกม |
| `lobbyTimeUrl` | `worldtimeapi.org/api/timezone/Asia/Bangkok` | API เวลาหลัก (คืนค่า `unixtime`) |
| `lobbyTimeFallbackUrl` | `https://www.google.com` | แหล่งเวลาสำรอง อ่านจาก HTTP `Date` header |
| `lobbyTimeSyncSeconds` | `60` | ความถี่ในการดึงเวลาจริง (วินาที) |
| `lobbyWeather` | `true` | ให้สภาพอากาศ Lobby ตามสภาพจริง |
| `lobbyWeatherLatitude` | `15.656812` | ละติจูดของพื้นที่ที่ใช้ดูอากาศ |
| `lobbyWeatherLongitude` | `103.588737` | ลองจิจูดของพื้นที่ที่ใช้ดูอากาศ |
| `lobbyWeatherUrl` | `https://api.open-meteo.com/v1/forecast` | Weather API (Open-Meteo ไม่ต้องใช้ key) |
| `lobbyWeatherSyncSeconds` | `600` | ความถี่ในการดึงสภาพอากาศ (วินาที) |

- **เวลา:** ม็อดดึง `unixtime` จาก API เวลาหลัก แล้วเดินเวลาต่อด้วย monotonic clock ภายในเครื่อง (ไม่ขึ้นกับเวลานาฬิกาเครื่อง) หาก API หลักล่มจะอ่าน `Date` header จากเว็บสำรอง หากล้มเหลวทั้งหมดจึงใช้เวลาของเครื่องเป็นทางเลือกสุดท้าย
- **สภาพอากาศ:** แปลงรหัส WMO จาก Open-Meteo เป็น `clear` / `rain` / `thunder` แล้วสั่งกับโลก `lobby` เท่านั้น (ปิด `advance_weather` เพื่อไม่ให้ vanilla สุ่มเปลี่ยนเอง) โลกหลักไม่ได้รับผลกระทบ

## 2. Resource Pack

- **ไม่มีเว็บเซิร์ฟเวอร์ในม็อดแล้ว:** พอร์ต 8085 และโค้ด HTTP API ถูกถอดออกจากโปรเจกต์ทั้งหมด การจัดการทุกอย่างทำผ่าน In-Game Custom Chest GUI 100%
- **การส่งมอบ Resource Pack:** ไฟล์ `resourcepack.zip` ถูกเผยแพร่เป็น asset ของ GitHub Release `latest` และไคลเอนต์ดาวน์โหลดผ่าน HTTPS โดยตรงจาก `server.properties`:
  ```properties
  resource-pack=https://github.com/TimeAndTimeStudio/Mod/releases/latest/download/resourcepack.zip
  resource-pack-sha1=<sha1 ของไฟล์>
  ```
  `setup.sh` ดาวน์โหลดไฟล์และคำนวณ `resource-pack-sha1` ให้อัตโนมัติ
- เมื่อมีการแก้ไข Resource Pack ในโฟลเดอร์รันเซิร์ฟเวอร์ ระบบจะโหลดไฟล์ล่าสุดจากดิสก์หรือทรัพยากรภายในม็อดโดยอัตโนมัติ

## 3. PvP ในเขตที่ดิน และโลก Lobby

- **PvP รายเขต:** เจ้าของเขตเปิด/ปิด PvP ได้จากเมนูจัดการเขต (ไอคอนดาบ = เปิด / โล่ = ปิด) กฎนี้ใช้กับทุกเขต — เมื่อปิด ผู้เล่นในเขตนั้นตีกันไม่ได้ ส่วนพื้นที่ว่างยังใช้ค่า `pvp` ของเซิร์ฟเวอร์ ค่าเริ่มต้นของเขตใหม่คือเปิด (`pvp=true`)
- **โลก Lobby:** `setup.sh` โหลดโลก `lobby` จาก `world-lobby-2026-11-17.zip` ไปวางที่ `worlds/lobby` และล้างข้อมูลผู้เล่นทั้งหมด ครอบคลุม player data, advancements และ stats
- **ม็อดสร้างโลก:** `setup.sh` โหลด lithostitched + tectonic (เฉพาะ 26.3) ไว้สร้างโลกหลัก โลก `lobby` เป็นโลกที่สร้างไว้แล้วจึงไม่ได้รับผลกระทบ
- **ม็อดเสริม:** `setup.sh` โหลด sit + otterlib (เฉพาะ 26.3) ลง `mods/` ไปด้วย

## 4. ความปลอดภัยและข้อมูลสำรอง

- **การจัดเก็บข้อมูลแบบ JSON:** ข้อมูลทั้งหมด (บัญชี, โฉนด, เศรษฐกิจ, ตลาดประมูล, กล่องพัสดุ) ถูกจัดเก็บในโฟลเดอร์ `config/timesmp/` ในรูปแบบไฟล์ JSON ที่สามารถสำรองข้อมูลได้อย่างง่ายดาย
- **รหัสผ่าน PBKDF2:** รหัสผ่านผู้เล่นผ่านการแฮชแบบ PBKDF2 ป้องกันการรั่วไหล
- **การสั่งรีโหลดข้อมูล:** ผู้ดูแลระบบสามารถใช้คำสั่ง `/timesmp reload` เพื่อโหลดข้อมูลการตั้งค่าและโฉนดที่ดินใหม่โดยไม่ต้องรีสตาร์ทเซิร์ฟเวอร์
